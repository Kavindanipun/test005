# MTB Glass Staff Stock Finder V7

Upload `index.html` to GitHub Pages repository root.

V7 shows the complete proof route for every Excel-based staff stock match: the exact Excel sheet cell, original raw row text, parentheses model when present, all cell models, linked original image, and recommended staff stock name. Every matching Excel cell is a separate result. Photos are embedded in HTML.

Example: OnePlus Nord N200 5G → MTB GLASS!D87 `(REAL 6)` → Realme 6 → Image 35 → OPPO A52.
